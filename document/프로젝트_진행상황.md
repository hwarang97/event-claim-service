## 완료한 작업

- IntelliJ에서 Spring Boot 프로젝트를 생성했다.
- 서버 실행과 `http://localhost:8080/` 접속을 확인했다.
  - 현재 `/`를 처리하는 Controller가 없으므로 404 Whitelabel Error Page가 보이는 것은 정상이다.
- Git 저장소를 생성하고 첫 커밋을 완료했다.
  - 커밋: `fbf35d3 chore: init project`
  - 브랜치: `main` (`origin/main`과 동기화)
- 줄바꿈 정책을 정리했다.
  - IntelliJ의 현재 프로젝트 새 파일 줄바꿈: LF
  - `.gitattributes`: 텍스트 파일은 LF, `.bat` 파일은 CRLF, `.jar` 파일은 바이너리
  - 전역 `core.autocrlf`는 변경하지 않는다. 이 프로젝트에서는 `.gitattributes` 규칙이 우선한다.

## 아직 하지 않은 설정

아래 항목은 필요해지는 구현 단계에서 하나씩 추가한다. 지금은 추가하지 않는다.

- MySQL 및 Docker Compose
- Spring Data JPA
- Flyway
- Swagger/OpenAPI
- Redis
- 실제 기능 테스트

## 작업 원칙

프로젝트 루트의 `AGENTS.md` 규칙을 따른다.

- 사용자가 명시적으로 요청하지 않으면 파일을 만들거나 수정하거나 삭제하지 않는다.
- 변경 전에는 대상 파일, 변경 내용, 이유를 먼저 설명한다.
- IntelliJ에서 가능한 작업은 사용자가 직접 수행하도록 한 단계씩 안내한다.
- 문서의 상태 갱신도 사용자의 명시적인 요청이 있을 때만 한다.
